# Trio prototypes

Interaction experiments for Trio. These are design prototypes, not production speech engines.

## Face-to-face portrait

The [portrait prototype](face2face/portrait/README.md) contains two comparable layouts: persistent green/blue cards with no visible dividing line, and the earlier split-screen divider. Both share fixed typography, independent append-only conversation logs, drag allocation, tap controls and hold-to-record simulation.

Open `face2face/portrait/index.html` locally in a browser. See the folder README for tests, direct preview states and remaining device-validation work.
